# Task01

## Структура файлов данных

### ratings.csv
Формат: `userId,movieId,rating,timestamp`
- `userId` — идентификатор пользователя (от 1 до 120)
- `movieId` — идентификатор фильма
- `rating` — оценка от 0.5 до 5.0
- `timestamp` — время оценки в формате Unix

### movies.csv
Формат: `movieId,title,genres`
- `movieId` — идентификатор фильма
- `title` — название фильма
- `genres` — жанры (через `|`)

## Результаты анализа

### ratings_count.txt
Содержит 2 строки:
1. Минимальный `userId` и количество строк с ним: `1 232`
2. Максимальный `userId` и количество строк с ним: `120 22`

### sqlite.txt
Содержит версию установленного SQLite и список доступных режимов вывода команды `.mode`.
